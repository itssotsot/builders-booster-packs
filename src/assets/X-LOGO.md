# X logo

`x-builders-logo.svg` uses the unmodified white X path from the official X brand toolkit, retrieved September 9, 2026:

- https://about.x.com/en/who-we-are/brand-toolkit
- https://about.x.com/content/dam/about-twitter/x/brand-toolkit/x-logo.zip (`logo.svg`)

The mark replaces the former terminal-in-a-pack symbol for X Builders. The same SVG is used in the header, loader, favicon, chooser, roster, empty collection, card backs and canvas-drawn pack title. Geometry and proportions are preserved; sizing is controlled by the UI or canvas renderer.
