# Artwork and third-party assets

The MIT license applies to original code and documentation, not the visual assets.
This is an unofficial fan project, not affiliated with or endorsed by OpenAI, X,
or the people depicted. Abilities and stats are fictional game content.

- `references/` and `public/assets/x-builders/` contain public portrait references.
  Source links identify provenance; this repository does not document permission
  to redistribute those photographs or grant a license to them.
- Generated portraits, wrappers, and creature artwork live in `public/assets/`.
  No asset license is granted by this repository. Depicted people and third-party
  marks are not covered by the source-code license.
- OpenAI and X logo provenance is documented in
  [OPENAI-LOGO.md](src/assets/OPENAI-LOGO.md) and [X-LOGO.md](src/assets/X-LOGO.md).
- Generation notes and OpenAI portrait sources are in
  [BUILDERS-ARTWORK.md](public/assets/BUILDERS-ARTWORK.md) and
  [BUILDERS-SOURCES.md](public/assets/BUILDERS-SOURCES.md).
  X Builders profile sources are recorded per person in `src/x-builders.js`.

Before redistributing visual assets, establish permission for the intended use
or replace them with assets you can distribute. This notice records the current
asset status; it does not establish missing permissions.
